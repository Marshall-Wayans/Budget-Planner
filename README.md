# Ledger — Personal Finance Command Center

A React + Vite + Tailwind rebuild of the expense tracker, expanded into a full
personal finance assistant: transactions, budgets, savings goals, debt payoff,
subscriptions, analytics, a money advisor, a 6-mode financial calculator, and
a what-if simulator. All data persists to localStorage via a single storage
service.

## Run it

```
npm install
npm run dev
```

Then open the printed local URL. `npm run build` produces a production build in `dist/`.
